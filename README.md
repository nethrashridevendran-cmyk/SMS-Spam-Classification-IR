# SMS Spam Classification – Information Retrieval

Comparative study of Decision Tree, KNN, SVM and Naïve Bayes for SMS spam classification using TF-IDF.

## Dataset
UCI SMS Spam Collection (Ham and Spam messages).

## Results
SVM achieved the best overall performance with 97.58% accuracy and an F1-score of 89.71%.
